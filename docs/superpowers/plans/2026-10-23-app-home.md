# Главная страница `/app` — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вместо плоского `/library` человек получает `/app`: полоска разделов, «Мои игры» с фильтрами и секциями по готовности в облаке, блок «Запускал недавно», правая колонка со Steam, потраченным временем и установками, плюс разделы «В тренде», «Из ящика» (заглушка) и «Время», с отдельной раскладкой для телефона.

**Architecture:** Сервер (`apps/api`, Effect 4 + Drizzle) только добавляет поля и запросы поверх существующих таблиц: статус игры в облаке из `gamestore_apps`/`install_jobs`, профиль из `profiles`, недавние игры и тренды из `sessions`, время из `play_segments`. Фронт (`apps/web`, React 19 + TanStack Router) получает новое дерево маршрутов `/app/*` с новыми компонентами в `components/app/`, чистой логикой фильтров в `lib/`, и в последней задаче переключает `/library` на `/app`, удаляя старые компоненты. Старые файлы библиотеки до переключения не трогаются (§7 спеки).

**Tech Stack:** Bun 1.4.4, Effect 4.0.5 (`effect/rpc`, `effect/reactivity`), Drizzle 1.0.0-rc.4 / PostgreSQL, React 19, TanStack Router 1.170, Tailwind 4, shadcn (`Button`, `Badge`, `Skeleton`, `Tooltip`), lucide-react, `bun test` + happy-dom + Testing Library. Новых зависимостей нет.

**Spec:** `docs/superpowers/specs/2026-10-23-app-home-design.md` (ниже «спека»). Прототипы: `docs/brand/prototypes/app-home.html` (десктоп), `docs/brand/prototypes/app-home-mobile.html` (телефон).
