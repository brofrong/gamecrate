# GameCrate — единая карточка, страница игры и доработка `/app` — дизайн

Статус: **реализовано 2026-10-27** на ветке `feat/app-game-page` (план `docs/superpowers/plans/2026-10-27-app-cards-and-game-page.md`), проверено на копии библиотеки владельца (1186 игр). Отклонения от текста ниже, принятые на прогоне: (1) у неустановленной игры на плитке справа **пусто**, а не «не установлена» — секция «Нужна установка» и кнопка «Установить» это уже говорят, а на телефоне слово съедало название; (2) закреплена ячейка сетки полоски в `AppShell`, а не сам `nav` (sticky на элементе, заполняющем родителя, не работает); (3) пятая колонка — именованный брейкпоинт `wide` (90rem) вместо `min-[1440px]:`, который Tailwind кладёт раньше `lg:`; (4) достижения запрашиваются **после** описания, а не параллельно с ним (решение «нет достижений → `None`» зависит от `achievementsTotal` из Steam Store, а лишний запрос к Steam Web API на каждую игру без достижений не нужен) — худший случай при медленном Steam не 5, а 10 с скелета; (5) если схема достижений не пришла — `None`, а не `Ready` с пустым списком. Согласовано с владельцем 2026-10-27 (брейнсторм с макетами). Строится поверх `main` (1ec73c8, главная `/app` из спеки `2026-10-23-app-home-design.md`). Решения, помеченные **[моё решение]**, владелец не проговаривал — их можно оспорить без переделки остального.

## 1. Зачем

Главная `/app` сделана и задеплоена, но владелец посмотрел на неё со своей библиотекой (1186 игр в Steam, 4 установлены в облаке) и назвал её сырой:

- карточки разные в разных секциях («Запускал недавно» — широкая карточка с датой, остальное — плитка), и у готовой игры слово «готова» написано дважды (плашка **ГОТОВА** на обложке и строка «готова · 14 ч» под ней);
- клик по игре ничего не открывает, а хочется страницу игры с нормальной информацией: описание, скриншоты и видео из Steam, совместимость, открытые достижения;
- в левой полоске кнопка «Установки» лишняя: «загрузок» как понятия у продукта нет;
- полоска уезжает при прокрутке.

Моя проверка на копии библиотеки владельца добавила: секция «Нужна установка» рисует все 1182 плитки сразу (страница высотой 51 000 px, 13 000 DOM-узлов), правая колонка тоже уезжает, у неустановленной игры кнопка называется «Играть».

## 2. Цели, не-цели, анти-цели

**Цели**

1. Одна карточка игры на все секции и разделы (`/app`, «В тренде»), без дублей статуса, с кликом на страницу игры.
2. Страница игры `/app/game/<appId>` с данными из Steam Store и Steam Web API: описание, скриншоты, трейлер, совместимость, достижения пользователя, его сессии.
3. Полоска слева без «Установок», закреплена; правая колонка закреплена.
4. Большая библиотека не убивает страницу: секции показывают первую порцию и «Показать ещё».

**Не-цели**

- Менять фильтры, сортировки, «Время», «В тренде» по содержанию, «Из ящика», телефонную нижнюю панель.
- Хранить медиа Steam у себя: картинки и видео отдаются по ссылкам Steam, кэшируются только тексты и метаданные.
- Отдельная сущность «установка» в RPC и управление установками (отмена, очередь) — остаётся как есть.
- Виртуализация сетки: «Показать ещё» достаточно.

**Анти-цели** (провал, даже если работает)

- Карточка, где статус игры написан два раза или разными словами в разных местах.
- Страница игры, которая при недоступном Steam Store показывает ошибку вместо того, что уже знаем (название, обложка, статус в облаке, кнопка).
- Слово «контейнер» в интерфейсе — только «облако». Steam ни в одном тексте не называется способом войти в GameCrate.

## 3. Что увидит человек

### 3.1 Левая полоска (`Rail`)

Содержимое как сейчас: логотип сверху, четыре раздела под ним («Мои игры», «В тренде», «Из ящика», «Время»), снизу «Поиск» и аватар-ссылка на `/profile`. Убирается кнопка «Установки» вместе с жёлтой точкой и пропсом `installing` (`AppShell` его больше не принимает; `?status=installing` в адресе остаётся рабочим фильтром).

Полоска закреплена относительно окна: не прокручивается с содержимым, высотой во всё окно минус отступы сетки (сверху и снизу по 24 px, как сейчас `md:p-6`), так что логотип всегда у верхнего края, аватар у нижнего **[моё решение — так я понял «всегда посередине экрана»]**. Между разделами и нижней группой — растяжка, как сейчас. На планшете то же; на телефоне полоски нет (нижняя панель без изменений).

### 3.2 Правая колонка

Закреплена так же, как полоска: верх на уровне заголовка, прокручивается только средняя колонка. Если панелей больше, чем влезает по высоте, колонка прокручивается внутри себя **[моё решение]**. Панель «Установки» (`InstallsPanel`) остаётся как есть (показывается, когда активная сессия устанавливается). На планшете (колонка под сеткой) ничего не закрепляется.

### 3.3 Карточка игры (вариант C с макета)

Одна и та же плитка во всех секциях «Моих игр», в «Запускал недавно» и в «В тренде». Горизонтальная обложка 460×215 (та же цепочка `header.jpg` → `coverUrl` → заглушка), **под обложкой ничего нет**. На обложке:

- внизу — затемнение градиентом и строка: слева название (одна строка, многоточие), справа одно короткое значение:

| Ситуация | Справа | Цвет |
|---|---|---|
| установлена, играл | `41 ч` — компактно, без «в игре»: новая функция `formatHoursShort` в `lib/formatTime.ts`, `formatHoursInGame` остаётся для других мест **[моё решение]** | приглушённый |
| установлена, не играл | `готова` | зелёный |
| качается | `42 %` (или `качается`, пока процент неизвестен) | жёлтый `#ffd166`, плюс полоса прогресса 3 px по нижнему краю обложки |
| не установлена | `не установлена` | приглушённый |
| нет профиля Steam у пользователя | `нужен вход в Steam` | приглушённый, обложка приглушена как сейчас |
| «В тренде», игры нет в библиотеке | `нет в библиотеке` | приглушённый |
| «Запускал недавно» | `вчера · 1 ч 20 мин` (дата и длительность последней сессии, как сейчас в `RecentCard`) | приглушённый |
| «В тренде» | `12 играют` / `34 игрока` | приглушённый |

  Секционный подписи («Запускал недавно», «В тренде») важнее статусных: в этих секциях статус игры в облаке не пишется словами — его видно по кнопке при наведении и на странице игры **[моё решение]**.
- справа сверху — тег Proton моно-шрифтом как сейчас (`pending` не показываем);
- плашки **ГОТОВА** и цветной точки больше нет;
- при наведении (на тач-экранах всегда) по центру обложки появляется кнопка: **«Играть»** для установленной, **«Установить»** (иконка `Download`) для «не установлена» и «качается» **[моё решение — обе ведут в тот же `session.start`: сессия сама ставит игру и запускает; разница только в слове]**, «Вернуться в игру» и блокировка при чужой активной сессии — как в `cardAction` сейчас. У игры «нет профиля» и «нет в библиотеке» кнопки нет (как сейчас).

Клик по любому месту плитки, кроме кнопки, открывает `/app/game/<appId>`. Плитка — `<a>` (TanStack `Link`) с `aria-label` «Игра: <название>», кнопка внутри — отдельный фокусируемый элемент, её клик не всплывает в ссылку. Название на обложке остаётся в разметке как `h3` для скринридеров.

Сетка плотнее: 2 колонки на телефоне, 3 на планшете, 4 на десктопе до 1440 px, 5 от 1440 px, зазор 12 px **[моё решение]**. `RecentRow` и `RecentCard` удаляются; «Запускал недавно» — та же `GameSection` с теми же плитками (до трёх, горизонтальная прокрутка на телефоне остаётся).

### 3.4 «Показать ещё»

Каждая секция «Моих игр» показывает первые 24 плитки **[моё решение — ровно 6 рядов по 4]**; если игр больше, под сеткой кнопка «Показать ещё 24 · осталось N», каждый клик добавляет 24. Счётчик в заголовке секции — общее число, как сейчас. Смена фильтров или поиска сбрасывает раскрытие. При непустом поиске порог тот же. «В тренде» (до 12) и «Запускал недавно» (до 3) не ограничиваются.

### 3.5 Страница игры `/app/game/<appId>`

Открывается внутри `AppShell` (полоска, нижняя панель на телефоне). Правой колонки нет — её содержимое на этой странице не нужно, средняя колонка занимает всю ширину **[моё решение]**. Сверху ссылка «← Мои игры» (история браузера, если пришли с `/app`, иначе просто `/app`).

**Шапка**: картинка `library_hero.jpg` на всю ширину (высота около 280 px на десктопе, 180 на телефоне), снизу затемнение; поверх — название крупно и ряд чипов:

- статус в облаке: `● В облаке` (зелёный) / `качается · 42 %` (жёлтый) / `не установлена`;
- `ProtonDB: platinum` (если не `pending`);
- `41 ч сыграно` (из `user_games.playtime_minutes`; 0 — чип не показываем);
- `последний запуск: вчера, 1 ч 20 мин` (из `sessions` пользователя; нет — не показываем).

Справа в шапке кнопка «Играть» / «Установить» / «Вернуться в игру» — та же `cardAction`, тот же `usePlaySession`. Если `library_hero.jpg` не загрузился — `header.jpg`, растянутый с размытием **[моё решение]**.

**Ниже две колонки** (на телефоне одна, в порядке: медиа, об игре, достижения, совместимость, факты, сессии):

Левая, широкая:

1. **Скриншоты и видео.** Первый элемент — трейлер (`movies[0]`, тот, где `highlight: true`, иначе первый): постер `thumbnail` с кнопкой ▶, по клику играет на месте через HLS (`hls_h264`): нативно, где `<video>` умеет `application/vnd.apple.mpegurl`, иначе через `hls.js` (новая зависимость `apps/web`) **[моё решение; Steam больше не отдаёт mp4/webm, только DASH/HLS]**. Далее скриншоты `path_thumbnail`, по клику открывается `path_full` в простом лайтбоксе (стрелки, Esc). Показываем первые 8, остальные — «ещё N» раскрывает всё.
2. **Об игре.** `short_description` и `about_the_game` (HTML Steam, прогнанный через санитайзер — разрешены `p, br, strong, em, ul, li, h2, img`; `img` только с доменов `*.steamstatic.com`) **[моё решение]**. Длинный текст свёрнут до ~6 строк с «Читать дальше».
3. **Достижения · 23 из 54.** Сетка иконок 48 px: открытые — цветная иконка `icon`, закрытые — `icongray` приглушённые; при наведении — название и описание в тултипе; порядок: открытые по дате получения (новые первые), затем закрытые. Показываем первые 32, «ещё N» раскрывает. Если у игры нет достижений (`achievements.total` = 0 или нет) — панели нет. Если Steam не отдал данные пользователя (профиль закрыт, `success: false`) — вместо сетки строка «Steam скрывает твои достижения. Открой «Сведения об играх» в настройках приватности Steam» со ссылкой на `https://steamcommunity.com/my/edit/settings`. Если у пользователя нет привязанного Steam — панели нет.

Правая, узкая:

4. **Совместимость.** Таблица ключ–значение: ProtonDB (цвет по тиру, как `tierLabel`), В облаке («установлена, 122 ГБ» из `gamestore_apps.size_bytes` / «качается» / «не установлена»), Геймпад (`controller_support`: `full` → «полная поддержка», `partial` → «частичная», нет → строки нет), Linux (`platforms.linux` → «есть нативная версия», иначе строки нет).
5. **Об игре** (факты): Разработчик (`developers`, через запятую), Издатель (если отличается), Выход (`release_date.date` как отдаёт Steam на русском), Жанры (`genres[].description`, до четырёх), Metacritic (`metacritic.score`, ссылка на `metacritic.url`), ссылка «Открыть в Steam ↗» на `https://store.steampowered.com/app/<appId>`.
6. **Мои сессии.** До 10 последних сессий пользователя в этой игре (не `failed`): дата (`formatRelativeDate`) и длительность (сумма `play_segments` сессии) моно-шрифтом; пусто — «Ты ещё не запускал эту игру в облаке». Ссылка «все сессии →» на `/app/time`.

**Состояния.** Пока грузится `library.game` — скелет шапки и панелей. Если Steam Store недоступен или игра там не найдена (`success: false` — бывает у удалённых из магазина и у инструментов), страница всё равно рисует шапку из того, что знает библиотека (название, статус, часы, тир, сессии) и одну панель «Steam не дал описание этой игры». Если `appId` не в библиотеке пользователя и не в `games` — экран «Этой игры нет в твоей библиотеке» с кнопкой на `/app` **[моё решение; «В тренде» ведёт на страницу и чужой игры — для неё показываем всё, кроме «Играть» и личных панелей]**. Нет сессии — редирект на `/login?next=/app/game/<id>`, как у остального `/app`.

### 3.6 Телефон

Карточки те же, две в ряд. Страница игры в одну колонку, кнопка «Играть» фиксируется над нижней панелью в `StickySlot`, пока шапка проскроллена **[моё решение]**. Видео играет в том же месте, не на весь экран.

## 4. Данные и RPC

### 4.1 Кэш данных Steam Store

Новая таблица `game_details` (миграция в `packages/db/migrations`):

| колонка | тип | что |
|---|---|---|
| `app_id` | integer PK → `games.app_id` | |
| `fetched_at` | timestamptz not null | когда последний раз спрашивали Steam |
| `found` | boolean not null | `success` ответа; `false` — Steam игру не знает |
| `short_description`, `about_the_game` | text | как у Steam, `l=russian` |
| `developers`, `publishers`, `genres` | text[] | |
| `release_date` | text | строка Steam («3 авг. 2023 г.») |
| `metacritic_score` | integer | |
| `metacritic_url` | text | |
| `controller_support` | text | `full` / `partial` / null |
| `linux` | boolean not null default false | `platforms.linux` |
| `achievements_total` | integer not null default 0 | |
| `screenshots` | jsonb | `[{thumb, full}]` |
| `movies` | jsonb | `[{name, thumbnail, hls, highlight}]` |

Срок жизни записи — 7 суток **[моё решение]**: `library.game` отдаёт то, что в базе, и если записи нет или она старше 7 суток — ходит в `https://store.steampowered.com/api/appdetails?appids=<id>&l=russian` (таймаут 5 с), сохраняет и отдаёт. При ошибке сети — отдаёт устаревшую запись, если есть, иначе `details: null`. Клиент `SteamStoreApi` в `apps/api/src/steam/` по образцу `ProtonDb` (никогда не падает). Один запрос за раз на один `appId` — без общего предзаполнения кэша по всей библиотеке: с 1186 играми это упёрлось бы в лимит Steam Store (~200 запросов за 5 минут).

Картинки шапки и карточек не хранятся: `https://cdn.cloudflare.steamstatic.com/steam/apps/<appId>/library_hero.jpg` и `header.jpg` строятся по `appId` на фронте (`cdn` и `store` с brofrong доступны, проверено 2026-10-27).

### 4.2 Достижения

Steam Web API, тот же `STEAM_API_KEY` (`SteamApi`):

- `ISteamUserStats/GetSchemaForGame/v2/?appid=` — названия, описания, иконки (`icon`, `icongray`). Кэшируется в `game_achievements` (`app_id`, `api_name` PK, `name`, `description`, `icon`, `icon_gray`, `hidden`) с тем же сроком 7 суток через поле `achievements_fetched_at` в `game_details`.
- `ISteamUserStats/GetPlayerAchievements/v1/?steamid=&appid=&l=russian` — открытые пользователем (`achieved`, `unlocktime`). Не кэшируется, запрашивается при каждом открытии страницы (таймаут 5 с). `success: false` с `error` «Profile is not public» → `achievements: {_tag: "Private"}`; игра без достижений или ошибка схемы → `{_tag: "None"}`.

`steamId` пользователя берётся как в `LibraryService` (поле `user.steamId`).

### 4.3 RPC

`packages/rpc/src/library.ts`, все под `AuthMiddleware`:

- `library.game` payload `{appId}` → `GameView`:
  ```
  {
    appId, name, coverUrl, cloud, protonTier,
    inLibrary: boolean,           // есть в user_games
    playtimeMinutes,              // 0, если не в библиотеке
    sizeBytes: number | null,     // gamestore_apps.size_bytes, если установлена
    lastSession: { startedAt, minutes } | null,
    sessions: Array<{ id, startedAt, minutes }>,   // до 10
    details: GameDetails | null,  // §4.1 без служебных полей
    achievements:
      | { _tag: "None" }
      | { _tag: "Private" }
      | { _tag: "Unlinked" }      // нет Steam у пользователя
      | { _tag: "Ready", total, unlocked: Array<{apiName, name, description, icon, unlockedAt}>,
          locked: Array<{apiName, name, description, iconGray, hidden}> }
  }
  ```
  Ошибки: `GameNotFound` (нет ни в `games`, ни в библиотеке) — отдельный тег, фронт показывает экран из §3.5.
- `library.recent` и `library.trending` — без изменений; `RecentEntry` уже несёт всё, что нужно плитке.
- `LibraryEntry` — без изменений.

Запросы к Steam Store и достижениям идут **параллельно** внутри `library.game` (`Effect.all` с `concurrency: "unbounded"`), общий ответ ждёт не дольше самого медленного (5 с).

## 5. Фронт

- Маршрут `/app/game/$appId` в `apps/web/src/routes/app.tsx` (дочерний `appRoute`, `params` → число, нечисло → редирект на `/app`). Атом `gameAtom(appId)` в `rpc.ts` по образцу `timeSummaryAtom`.
- `GameTile` переписывается под §3.3: пропсы `game: TileGame`, `action: CardAction`, `caption?: string` (правый текст секции, если задан — перекрывает статусный), `dimmed`. `cloudLabel` заменяется на `tileValue(game, dimmed): {text, tone: "muted" | "ok" | "warn"}` в `lib/` (чистая функция, тесты). `RecentRow.tsx` удаляется, `MyGamesPage` рисует «Запускал недавно» через `GameSection` + `GameTile` с `caption`.
