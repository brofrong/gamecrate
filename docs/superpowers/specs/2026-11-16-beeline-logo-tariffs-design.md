# Витрина билайна: логотип и тарифы со старого сайта

Дата: 2026-11-16. Продолжение [мульти-бренда](2026-11-16-multi-brand-design.md).

## Зачем

Владелец: «на главной билайна в левом верхнем углу вставь лого билайна. и там где тарифы можешь
перенести тарифы со старого сайта с переносом информации о тарифах с плюсами». Старый сайт —
beeplaycloud.ru. Витрина должна выглядеть как продукт билайна, а абонент — видеть те же
подписки, что раньше.

## Решения владельца (2026-11-16)

- Вход на витрине билайна — только по SMS, без сторонних сервисов. SMS — **через API билайна**
  (как подписка на старом сайте). Пока нет документации и доступов от билайна, SMS не делаем.
- До SMS вход по коду на почту на витрине билайна **остаётся**. Pocket ID на beeline-домене уже
  выключен (`OAUTH_HOSTS_POCKET_ID` на srv5 = только gamecrate-домен).
- Тарифы — **карточками на витрине** (информация + плюсы). Начисление часов по ним — вместе с
  API билайна, не сейчас.

## Подходы к тарифам

1. **Данные в реестре бренда (выбран).** Список подписок — поле `monetization.plans` в
   `apps/web/src/brands/beeline`. Тексты меняются коммитом, без базы и админки. Подходит, пока
   подписка продаётся у билайна, а не у нас.
2. Тарифы в базе с привязкой к бренду. Нужна схема, админка, начисление по дням/неделям — это
   работа вместе с API билайна, сейчас лишняя.
3. Загружать с API старого сайта. Зависимость от чужого сервера, который уйдёт.

## Что меняется

**Логотип.** `BeelineLogo` рисует фирменный шар билайна из `beeline-ball.svg` старого сайта
(тот же знак стоит там в левом верхнем углу шапки). Без слова рядом, как на старом сайте; в
шапке лендинга, футере, чате FAQ и в приложении — тот же знак. `favicon.svg` витрины — тот же
шар; `apple-touch-icon.png` — растр шара 180×180.

**Тарифы.** Тип `partner` получает `plans: readonly PartnerPlan[]`:
`{ name, price, priceNote, perks: readonly string[] }`. Данные билайна (тексты старого сайта,
дословно):

| Подписка | Цена | Плюсы |
|---|---|---|
| Стандартная подписка | 75 ₽ — подключение, 1 час | получай часы ежедневно; бонусные часы за активное использование |
| Недельная подписка | 299 ₽ — подключение, 7 часов | получай часы каждую неделю |

Карточки (общий компонент) показываются в секции «Подписка» лендинга (`PartnerSubscription`)
и на `/app/plans` (`PartnerPlansPage`) над блоком «Ваш тариф». Кнопки «Подключить» на карточке
нет, пока у бренда нет `monetization.url` (подключение — у билайна); когда адрес появится —
кнопка ведёт туда. Пустой `plans` — карточек нет, страница как сейчас.

**Мои решения (можно поправить):** пакеты 1/3/5 часов и конфигурации «обычная»/«ультра»
(1,5 и 2 ₽/мин) не переносим: цен пакетов в коде старого сайта нет, а поминутной оплаты и
выбора конфигурации у нас нет. Добавить — одна строка данных на позицию.

## Не входит

SMS-вход и проверка подписки через API билайна, начисление часов по подписке, отдельные тарифы
в базе для бренда.

## Проверка

Тесты web: карточки рендерятся из `plans` (название, цена, плюсы), без `url` нет кнопки, с `url`
кнопка ведёт на него, пустой список — без секции; у GameCrate ничего не меняется. Глазами —
beeline.srv5.wbrofrong.ru (главная, `/app/plans`) после выкатки.
